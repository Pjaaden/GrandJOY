# GrandJOY · 大悦城招商资源库

> 大悦城总部招商（运动户外 / 潮流服饰板块）的全国品牌资源挖掘与展会情报库。
> 与 `Brand-Engine`（品牌动向监测）、`Stock-Research`（股票投研）是**三个独立项目**，各自独立 git 仓库、独立同步。

## 项目定位

面向全国范围的**品牌资源挖掘**：展会情报梳理、品牌线索沉淀、踩展复盘。
聚焦两大业态板块：**运动户外**、**潮流服饰**。

## 目录结构

```
GrandJOY/
├── 00-索引/
│   └── 项目文件索引.md              # 全部产出的入口索引
├── 01-展会梳理/                     # 全国性展会名单与年度时间表
├── 02-品牌线索/                     # 踩展/调研沉淀的品牌线索台账
├── 03-脚本与归档/                   # 脚本与历史归档
├── scripts/                         # 双击式同步工具（开工/收工）
├── TRAE_LOCAL/                      # 本地凭证区（.gitignore，不入库）
└── .trae/rules/                     # TRAE 项目规则
```

## 三设备同步使用

| 时机 | 操作 |
|---|---|
| 开工 | 双击 `scripts/开工.command`（或让 TRAE 的 AI 帮你"拉取最新"） |
| 收工 | 双击 `scripts/收工.command`（或让 TRAE 的 AI 帮你"提交并推送"） |
| 纪律 | 同一时段尽量只有一台设备推送，其他设备只读 |
| 冲突 | 出现 ⚠️ 提示时截图发给 TRAE 里的 AI 处理，不强行覆盖 |

远端仓库：`git@github.com:Pjaaden/GrandJOY.git`（SSH 通道，账号 Pjaaden）

## 任务归属约定

TRAE 中可能同时进行多个项目的对话。**每个任务开始时，必须先声明所属项目**：

- 说「项目：GrandJOY」→ 属于招商资源挖掘，文件只写入本文件夹
- 说「项目：Brand-Engine」→ 属于品牌监测
- 说「项目：Stock-Research」→ 属于股票研究
