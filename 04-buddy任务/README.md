# 04-buddy任务（Buddy 任务区）

> 本目录由 **GrandjoyBuddy（buddy）** 承接的每个独立任务各自使用一个子文件夹，
> 与 TRAE 的业务产出（00-索引 / 01-展会梳理 / 02-品牌线索 / 03-脚本与归档）隔离，
> 防止文件结构混乱。

## 命名约定

- 每个任务一个子文件夹：`buddy-YYYYMMDD-<任务简述>/`
- 例：`buddy-20261029-GitHub权限梳理/`
- 该任务的**全部产出**（正文、脚本、草稿、素材）都放进对应子文件夹，
  不散落在根目录，也不混入 00-03 业务目录。

## 生命周期

1. **任务开始** → 在 `04-buddy任务/` 下新建 `buddy-YYYYMMDD-<任务简述>/`
2. **任务过程** → 中间文件、脚本、草稿都放该子文件夹
3. **任务结束** → 如为长期有效产出，在 `00-索引/项目文件索引.md` 登记
4. **收工同步** → 正常 git 提交推送（同项目同步纪律）
