## 一、古良吉吉（KUNOGIGI）

**品牌名称：**[古良吉吉 KUNOGIGI（广州古良吉吉服饰实业有限公司 / 隶属古良文化集团）]

**所属业态：**[原创设计师包袋（时尚皮具 / 箱包）]

**核心客群：**[25–34 岁都市"玩童"，新一线及一线城市女性为主；不愿背快时尚爆款、又够不到奢侈品牌的"不费力的时髦"客群，客单 600–1600 元]

**全国门店数量：**[30+ 家实体门店（其中经销 20+），约 50% 进驻万象系项目；深圳湾万象城、成都、合肥、西安、天津、长沙、拉萨、昆明、南宁、无锡等]

**市场定位及拓展需求：**[千元以内新锐头部设计师包袋，主攻一二线城市中高端及以上商场核心铺位，与国际轻奢同层竞合；目标门店约 50 家、线下销售占比提至 20–25%，并试水东南亚市场]

**竞争优势：**[原创设计 + 自建"古良工坊"，供应链快反最快 5–7 天出货；多巴胺童趣设计语言与高辨识度爆品（烟盒包累计销售过亿）；线上全渠道基本盘扎实，2023 年全渠道销售近 3 亿；联名与文化 IP 能力强（喜茶、秦始皇陵博物院、《乘风 2023》、自有"古良茶楼"）；直营 + 经销双轨，单店可复制、风险可控]

**空间规划建议：**[80–150㎡ 体验店，"玩新工坊"主题，一店一策做在地文化定制（拉萨=游牧村落、昆明=白族扎染工坊、南宁=壮寨高脚屋、杭州=织造工坊、深圳=渔港工坊）；陈列与手作工坊、社群活动（手工体验课、许愿锁）结合，主推可陈列可体验的"店铺即工坊"]

## 二、浴见（BATHFEEL）

**品牌名称：**[浴见 BATHFEEL（长沙创立，长沙 + 上海双总部，上海为线下运营总部）]

**所属业态：**[高端身体护理 / 香氛个护（浴室场景生活方式零售）]

**核心客群：**[28–40 岁"Super Girl"，一线及新一线城市占七成，25–34 岁女性超四成；经济独立、爱阅读爱运动养宠物，注重身体与情绪的双重护理，客单 350–400 元（大促区间）]

**全国门店数量：**[5 家（上海上生新所首店、长沙、无锡、南京、北京前门西兴隆街华北首店）；北京店 2026-10-15 开业，为线下第五店]

**市场定位及拓展需求：**[国货高端身体护理头部、沐浴油品类国货第一；线上起家后战略重心转向线下，未来一两年以开店为战略重点，主攻一二线核心商圈及有调性的文化街区、街区型非标铺位]

**竞争优势：**[避开标品价格战，卡位"以油养肤"非标功效赛道；品牌价值结构 50% 功能 + 35% 情绪 + 15% 文化，差异鲜明；爆品猪鬃浴刷累计售出 60 万+ 把并连续三年居淘系品类前列；2025 年获贝泰妮战略投资 20% 成第二大股东，植物研发与渠道协同加持；线下店已实现盈利，客均购买 3 件、连带率 3]

**空间规划建议：**[分级店型——S 级旗舰 250㎡（产品陈列不足 100㎡，其余让渡给策展、体验、社群，如《身体新知》刊物、迷你展览、洗手台护理仪式）；A 级 80–150㎡"麻雀虽小、五脏俱全"；B 级交通枢纽店随买随走；统一"浴室"母题、一店一策主题命名（自由浴室 / 深夜浴室 / 自在浴室 / 留白浴室 / 书写者的浴室），重体验轻货架]

## 附：招商对接备注（内部用，不放正文）

**古良吉吉**
- 已高度绑定万象系（近 50% 门店在万象项目），万象城与大悦城客群结构高度重合，属可直接平移的选址标的；建议以"手作工坊 + 在地文化"做差异化，避开纯快时尚包袋的常规楼层。
- 经销 20+ / 直营约 10 的结构 → 大悦城可优先谈直营或城市合伙人，首店建议放在核心铺位做形象店，锁定后续区域拓展。
- 计划东南亚 → 对外拓有明确诉求，二线强三线（武汉、成都、西安、长沙、南京、合肥）均可推进。

**浴见**
- 目前仅 5 店、每店独立命名且主题不重复，对"唯一性"敏感 → 谈判核心是铺位调性与其「浴室」母题的契合度，而非面积和扣点。
- 选址偏好已明确偏向"慢而有品、自得其乐"的街区型商圈（北京前门西兴隆街）→ 优先匹配大悦城有街区、巷弄、露台等非标属性的项目，常规盒子里的标准铺位需重新做店型提案。
- 刚获贝泰妮投资、线上强线下弱，处于扩张窗口期，对新渠道开放度高，是当前较低成本的卡位机会。
