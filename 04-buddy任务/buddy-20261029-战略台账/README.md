## 三、三个必须知道的口径

### 1. 明细粒度 = 合同期次，不是合同
BI 导出的每一行是合同的一个**期次**。`合同期间` 列 1 = 第一期、2 = 第二期……
`起租日`/`到期日`是**该期次的边界**，不是整份合同的总边界（合同总边界在「合同级汇总」里）。

### 2. 面积类指标只在合同级看
同一份合同的多个期次重复记同一个面积。**明细表直接求和会重复计数**，
所以「合同级汇总」「区域业态汇总」「品牌汇总」的面积均按合同级统计（取合同内面积最大值，不累加期次）。

### 3. 抽成制合同没有固定租金
71 行 `单位日租金` 与 `期间固定租金总额` 为空，是纯抽成或两者取高合同的正常表现，不是数据缺失。
`抽成扣率` 以小数存储（0.16 = 16%），飞书里显示为 `16.00%`，可直接参与计算。

## 四、数据校验结果

台账内置 `数据校验` 列，对每行做 BI 口径复核（全量 925 行）：

| 校验结论 | 行数 | 含义 |
|---|---|---|
| 一致 | 782 | BI 值 = 日租金 × 面积 × (期间天数 − 免租期) |
| 抽成制·BI无固定租金 | 71 | 纯抽成合同，BI 侧本就不出固定租金 |
| 口径差异·两者取高 | 57 | BI 有额外取高逻辑，差异可接受 |
| 免租期超期·负值 | 14 | 免租期天数超过期次长度，BI 出负值 |
| 口径差异 | 1 | 单条差异，`固定租金校验差异` 列有具体金额 |

期间物业费 / 推广费总额口径已反推验证：
`BI 值 ≈ 单价 × 签约面积 × 期间天数 ÷ (365/12)`（月面积按 30.4167 天折算）。

**三级交叉校验**：合同级 ↔ 明细 ↔ 区域汇总的固定租金合计完全一致（差额 0.00 元），面积合计一致。

## 五、更新机制

### 日常更新（3 步）

```bash
# 1. 把新版 BI 导出放进 源数据/ 目录
cp ~/Downloads/运动男装合同台账1105.xlsx 源数据/

# 2. 双击或执行
bash 脚本/更新台账.sh

# 3. 完成。也可指定文件：
bash 脚本/更新台账.sh 源数据/某个文件.xlsx
```

脚本自动完成 5 件事：

1. 生成/覆盖本地 Excel（`产出/全国运动男装战略品牌合同台账_<版本>.xlsx`）
2. 覆盖刷新飞书同名表的所有数据子表（**先清空再写**，行数变少不会残留旧行）
3. 重建台账看板（含到期预警区块）
4. 重建到期预警条件格式 + 对齐子表顺序
5. 追加一条版本记录（同一数据版本重复跑会自动跳过，不重复记）

### 本地查询工具

不用打开飞书也能查，命令行直接出结果：

```bash
python 脚本/查台账.py 到期 --品牌 安踏 --月数 12    # 安踏系 12 个月内到期
python 脚本/查台账.py 到期 --商户 斐乐 --月数 6      # 某商户临期
python 脚本/查台账.py 合同 --品牌 耐克               # 某品牌全部在租合同
python 脚本/查台账.py 品牌                           # 品牌规模排行
python 脚本/查台账.py 区域                           # 区域×业态分布
python 脚本/查台账.py 项目                           # 项目维度汇总
python 脚本/查台账.py 校验                           # 数据校验分布与差异明细
```

`--品牌` 支持集团名（安踏 / 耐克 / 李宁 / 波司登 / 新百伦 / 骆驼 / 斐乐），
自动展开成旗下全部品牌 + 控股的 Amer Sports 品牌。

## 七、注意事项

- 飞书表的「合同台账明细」有 29 列 × 925 行，**后续如需手工改数请谨慎**——下次跑更新脚本会被覆盖，修改应落在 BI 侧
- 抽成扣率在 BI 里是 0.16 这样的小数，台账沿用同一口径；若 BI 改用 16 这样的百分数，脚本会自动识别失败并报错，不会静默出错
- 飞书 sheet 里若新增了自定义子表，更新脚本不会动它（只刷新 6 个数据子表 + 看板），但子表顺序会被重新对齐到标准顺序
- 到期预警以「合同到期日」为准（整份合同的总边界），不是期次边界——期次到期日会重复计算同一份合同
