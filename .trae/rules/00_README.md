# GrandJOY 项目规则

## 任务归属声明（必读）

本机 TRAE 可能同时服务于多个项目（GrandJOY / Brand-Engine / Stock-Research）。

- 每个任务开始时，用户会声明所属项目，例如「项目：GrandJOY」。
- 收到声明后：所有产出的文件**只写入 `/Users/Shared/Projects/GrandJOY/`** 下，
  不得把招商资源相关文件写入 Brand-Engine、Stock-Research 或其他项目目录。
- 若任务开始时未声明，先询问用户属于哪个项目。

## 项目定位

大悦城总部招商（**运动户外**、**潮流服饰**板块）的全国品牌资源挖掘：

| 板块 | 内容 |
|---|---|
| 展会情报 | 全国性消费类展会名单、年度时间表、踩展价值判断 |
| 品牌线索 | 从展会/渠道挖掘到的品牌线索台账（含开店意图、渠道现状） |

## 输出端硬规则

1. 展会名单以 `01-展会梳理/` 下**唯一主文档**形式持续更新，禁止另建带日期后缀的重复名单；每轮更新直接在原文档上修订，日期写入文档头「最近更新」。
2. **不编造**：展会时间、地点、主办方、规模等事实必须带来源链接；无法确认的必须标注「待确认」。
3. 名单口径为「**品牌方亲自参展的消费类展会**」——上游供应链/面辅料展、纯产业会议/文旅活动需在文中单独标注或排除。
4. 新产出后同步更新 `00-索引/项目文件索引.md`。
5. **Buddy 任务隔离**：GrandjoyBuddy（buddy）承接的任务，产出统一放
   `04-buddy任务/buddy-<日期>-<任务简述>/`，每任务一个独立子文件夹，
   不与 00-03 业务目录混放。

## 同步纪律

- 开工先拉取：`git pull --rebase origin main`
- 收工再推送：`git add -A && git commit && git pull --rebase && git push`
- 同一时段单一写者，避免冲突；冲突时不强行覆盖，先比对再合并。
- 凭证类只放 `TRAE_LOCAL/`（已 .gitignore），绝不入库。
