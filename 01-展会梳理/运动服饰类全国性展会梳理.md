### 1.2 关键判断（先看这三条）

1. **运动户外板块的最佳主场是 ISPO（上海 7 月 + 北京 1 月）**，没有之一。它是唯一同时满足「品牌方亲自设展位 + 官方 B2B 渠道拓展定位 + 中小品牌密度高」的场次。
2. **潮流服饰板块没有单一主场，要靠「CHIC + 上海订货会季（3月/10月）」组合拳**。纯潮流嘉年华类（YO'HOOD / INNERSECT）已停办，现存潮流类多为港澳 C 端活动，内地缺乏对标场次。
3. **「白牌转品牌」的富矿在广交会第三期**。运动服及休闲服可出口主体近两千家，其中相当一部分正在从代工转向自主品牌 + 内销线下渠道，这是招商岗最容易出成果、也最容易被同行忽略的口子。

## 四、踩展策略建议

### 4.1 全年三波踩展节奏

| 波次 | 时间 | 目标场次 | 主攻方向 |
|---|---|---|---|
| **第一波（开年）** | 1月 | ISPO BEIJING | 冬季户外/滑雪/保暖服饰品牌，全年首轮洽谈 |
| **第二波（最高峰）** | 3月 | CHIC（3.10–12）+ 上海订货会季（MODE / ONTIMESHOW / 时堂 / LABELHOOD，3月中下旬）+ IWF（3.12–14） | 一周内**连踩三场**：服饰品牌（CHIC）→ 设计师/新锐（订货会群）→ 健身鞋服（IWF） |
| **第三波（主展）** | 7月 | ISPO SHANGHAI（7.1–4） | 运动户外/运动时尚品牌集中洽谈 |
| **补充窗口** | 5月 / 10–11月 | 体博会（成都）、China Cycle（上海）、广州户外展 + 广交会三期 + 进博会 | 骑行/综合运动 + 白牌转品牌孵化池 + 国际品牌跨界观察 |

### 4.2 分板块打法

**运动户外**
1. **ISPO 系（上海+北京）为主战场**：提前索取展商名录，按「是否有线下门店 / 门店数量 / 是否有招商加盟政策」预筛，现场只谈重点。
2. **户外新锐（COSP / CLE）作补充**：中小品牌多、决策链短，是**首店/快闪**最容易谈成的对象。
3. **水陆空细分（水上运动展 / China Cycle / 冬博会）**按大悦城各项目定位择机。

**潮流服饰**
1. **CHIC 主打「运动休闲」展区**，但需从供应链企业中筛出**真正的品牌方**。
2. **上海订货会季（3月/10月）建线索库**：品牌方密集但以订货为目的，目标是**拿联系人与品牌资料**，会后转化。
3. **港澳潮流场（ComplexCon / Sneaker Con）**用于观察头部潮流资源与联名趋势，不指望现场招商。

**易被忽略的口子**
- **广交会第三期运动服及休闲服展区**：1932 家可出口主体中，正在从代工转自主品牌 + 内销渠道路线的一批企业，是最容易被同行忽略的招商富矿。
- **得物线下 IP（有点东西大会 / 野王30项）**：不是展会，但潮流/运动品牌方与年轻客群集中，可直接接触品牌市场团队。

### 4.3 现场作业清单（建议固化）

1. 展前：索取展商名录 → 按板块/是否有线下渠道预筛 → 排出每日重点展位路线。
2. 现场：每展位记录「品牌名 / 品类 / 现有渠道 / 是否有加盟或直营扩张计划 / 对接人 / 联系方式」。
3. 会后：48 小时内录入 `02-品牌线索/` 台账并分级（可立即洽谈 / 需持续跟进 / 暂不匹配）。
4. 复盘：更新本文件 §五待确认清单与 §二时间表。
