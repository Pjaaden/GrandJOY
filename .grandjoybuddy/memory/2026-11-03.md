### 飞书公式能力实测（做表格页前必读）
- ✗ FILTER 动态数组溢出 → #REF!（不能一行筛选）
- ✗ SMALL(跨表区域,k) / AGGREGATE(跨表区域) → #REF!/#VALUE!（**SMALL 必须同表**）
- ✓ INDEX(跨表区域, 标量行号) 可用
- ✗ **+cells-set 会把日期/数字写成文本** → 文本日期比较是按字符比的（全错）、文本数字无法参与求和
  → 快照必须用 **+table-put typed 协议**（dtype=datetime64[ns]/float64）写
- ⚠ `"" > 0` 在表格里是 **TRUE**（空串当文本）→ 统计命中数要用 `ISNUMBER()`，不能用 `>0`
- ⚠ `INDEX(区域,"")` 返回**首行**内容 → 空指针必须显式 `IF(指针="","",INDEX(...))`
- ⚠ body 从 A1 写入时 body[i] → 表格第 i+1 行；**行号必须由 body 长度推导**，写死常量会整体错位一行
- ⚠ 子表列数不够时 +cells-set 写超界**静默失败不报错** → 先 +dim-insert 扩列（--count 必须传字符串）
- ⚠ +cells-batch-clear 遇到子表上残留的筛选器会「返回 ok 但不清空被筛掉的行」
  → 推送前先 +filter-delete（推送飞书.py 已自动处理）
- 多选下拉取值是逗号分隔字符串（"NIKE,李宁"），匹配必须逗号包裹，否则「李宁」误命中「李宁YOUNG」
