### 三个必须记住的口径坑
1. **⚠ 台账里根本没有 ANTA KIDS**。其他儿童线（FILA KIDS / 耐克儿童 / NB Kids / MLB KIDS /
   UA KIDS / 特步儿童）都在，独缺安踏儿童 → 需确认是否在「运动+男装」筛选范围外
2. **⚠ 租金制式必须分三态，否则「月成本」横向比较会严重误导**：
   - 两者取高且有日租 → 可直接比
   - 两者取高但日租=0 → **无保底**（绍兴、北京大兴、鞍山特步儿童、烟台特步儿童）
   - 纯抽成（ANTA SUPERSTORE 厦门，日租0 扣率9%）→ 商场**无固定租金**，
     月成本只含物业+推广，实收要用销售额×扣率算 → 表格已加「租金制式」列
3. **⚠ 铺位状态要分三态**，不能都是「无在租期次」：
   在租 23 / 未起租 2（成都大悦城 2F-068、2F-070A 与成都大悦城悦街 2F-J05，
   2026-11-20 开业）/ 空置·合同已过期 2（天津大悦城 1F-A2、特步儿童昆明 3-4-12）
   - 特步儿童昆明合同 `HT2023033000087` 到期 2023-09-30、状态「审核中」→ 历史遗留未生效
4. **店型标注不统一**：`ANTA GUANJUN`/`ANTA SUPERSTORE` 标在品牌字段，
   而「ANTA 冠军」「ANTA 殿堂」只在**店铺名称**字段（品牌字段仍是 ANTA）。
   → 台账的明细层/合同层**不保留「店铺名称」**，需从 BI 源表按合同编号补映射
5. **续约优先级不能给已过期铺位打 P0**（负天数），已改为「已过期·待核查」单独归类
