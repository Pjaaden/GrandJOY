## 招调/续约口径铁律（2026-11-02 用户明确确立）
- **台账 = 合同当前版本；招调报告 = 「计划续约/调改」方案。方案不得回写台账。**
  台账内容非明确提示「补充/更改」时，不做数据类更改。
- 现行租金一律取 **系统内合同版本**，不采信项目招调报告里的「现租金」（可能是错的或旧口径）。
  典型案例：EVISU B121 系统合同 **17.50**，项目报 15.50 → 以 17.50 为准，15.50 只作续约报价放「计划日租」
- 现行列 vs 计划列分工：现行列仅当台账**录入错**（品牌名不符/费率录错）才用覆盖表；计划列本就独立于台账，可自由覆盖
- **租金涨幅 = 计划日租 ÷ 现行日租 − 1，必须实算**，不采信招调表手填涨幅（招调表常用历史旧价作基数）
- **招调报告的「现租金」栏最容易填错**：常被直接抄成「计划租金」。
  已遇 2 例：EVISU 报 15.50（合同 17.50）、E320-321 报 2.00（合同 6.00，2.00 是降租目标）。
  → 凡「现租金」与台账对不上，先怀疑这一栏填错，不是台账错
- **「起租日」要的是品牌在该铺位的「最初合同起始日」，不是当前这一期合同的起租日。**
  取数口径：台账「承租期-起租日」是**合同级字段**，同一合同多期次值相同 = 整条合同链起租日；
  或取该铺位最早一份合同期次1的「起租日」。两者一致。
  注意：年度续约合同常被系统把起租日写成当年 1 月 1 日，**不能直接当首进日**
  （2026-11-03 已闭合：EVISU B121 在 20261102 版 BI 里「承租期-起租日」= 2023-06-01，即真实首进日；
   此前 1029 版查无此合同才需靠补录台账 + 销售月报反推，现不再需要）

## ⚠ 飞书表格公式页铁律（2026-11-03 血泪教训，务必先读）
- **公式页绝不能做重。** 曾因跨表 INDEX/MAXIFS/SUMPRODUCT 组合（一次重算触碰约 1057 万单元格）
  把整张战略台账拖垮，40+ 分钟不可读，**连删子表都失败**。
  做飞书公式页前**先在沙箱表验证重算量级**；公式页只用「静态快照 + 轻量公式」。
- 飞书公式能力实测：
  - ✗ FILTER 动态数组溢出 → `#REF!`（不能一行筛选）
  - ✗ `SMALL(跨表区域,k)` / `AGGREGATE(跨表区域)` → `#REF!`（**SMALL 必须同表**）
  - ✓ `INDEX(跨表区域, 标量行号)` 可用
  - ✗ **+cells-set 把日期/数字写成文本** → 文本日期比较按字符比（全错）、文本数字无法求和
    → 快照必须用 **+table-put typed 协议**（dtype=datetime64[ns]/float64）
  - ⚠ `"" > 0` 是 **TRUE**（空串当文本）→ 统计命中数用 `ISNUMBER()`，不能用 `>0`
  - ⚠ `INDEX(区域,"")` 返回**首行** → 空指针要显式 `IF(指针="","",INDEX(...))`
  - ⚠ body 从 A1 写入时 body[i] → 表格第 i+1 行；**行号必须由 body 长度推导**
  - ⚠ 子表列数不够时 +cells-set 写超界**静默失败** → 先 +dim-insert 扩列（--count 传字符串）
  - ⚠ +cells-batch-clear 遇残留筛选器会「返回 ok 但不清空被筛掉的行」→ 先 +filter-delete
  - 多选下拉取值是逗号分隔串，匹配要逗号包裹，否则「李宁」误命中「李宁YOUNG」

## 飞书 CLI 使用要点（踩过的坑）
- `+cells-set --cells` 空位必须用 `{}`，不能用 `{"value": null}` —— 否则 schema 校验失败且静默返回空
- `+cells-batch-clear --ranges` 用子表**显示名**（`Sheet名!A1:H200`），不接受 `--sheet-id`；目标子表不存在会整体失败
- 覆盖刷新前先清空目标区域，避免行数变少残留旧行
- **清空只清内容不清格式**：列数变化时旧列残留日期格式会让新写入的整数显示成 1900-01-01 → 写入时必须**逐列显式声明 number_format**
- 表格数据写入用 `+table-put --sheets` typed 协议保类型（日期/金额/百分比）
- 条件格式用 `+cond-format-create --rule-type expression --ranges '["A2:P500"]' --properties '{"style":{"back_color":"#FFE3E3"},"attrs":[{"formula":["=$A2=\"🔴 90天内到期\""]}]}'`
- `+csv-get` 的 `--include-row-prefix` 是**布尔开关**，要写成 `--include-row-prefix=false`；
  写成 `--include-row-prefix false`（空格）会报 "positional arguments are not supported"
- ⚠ **飞书 CLI 出错时把 JSON 错误体写到 stderr、stdout 为空** —— 只 `json.loads(p.stdout)` 会拿到 `{}`，
  看不出真实错误码（40400 重试逻辑会因此失效）。**stdout 和 stderr 都要试解析**
- ⚠ `drive +update-title` 在「标题与当前完全相同」时返回 **981001 internal error** —— 属于无变化的正常情况，
  应按成功处理，否则每次幂等重跑都误报失败
- `+cells-get` 要**同时**写 `--include value --include formula` 才看得到公式，否则只返回计算值
  （公式一旦被误写成静态值，只读 value 会误以为「显示 0」是数据问题）
- 读到的 `annotated_csv` 里逗号可能被引号包裹（金额 `"3,702,342.00"`），
  逐行 `.split(',')` 会错位 → 必须用 `csv.reader`
- 明细表真实列名是 `单位日租金(元/平方米/日)`、`签约面积`，**不是** `日租金`、`签约面积(㎡)`
