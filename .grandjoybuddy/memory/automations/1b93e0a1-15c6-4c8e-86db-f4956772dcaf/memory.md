- 预览页同比负数用户写成 `−25.1%` 文本（General），非负数走 0.00%；合计行租售比写 `30.3% → 29.7%`
- 主表 AC「手动备注」为纯手填列：不套表头样式（宋体11无边框）、不并入 A1:AB1 合并区、脚本不写入
- 主题色 tint 0.8 与硬编码 D9E2F3 是同色，比对需归一化否则产生大量假差异
